# CMX context

Shared vocabulary for this repo. Normative shape detail: GitHub issue `#84` (`Contract: CMX document, dependency, environment, and render shapes`).

## Glossary

- **Hop** — Handoff between layers: one part produces a value, another stores or routes it, another operates and may return. Process term, not a network hop.
- **Leaf** — A part of the systems responsibility tree that that no longer delegates to other parts.
